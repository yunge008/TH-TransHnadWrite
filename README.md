# TH-TransHnadWrite

手写机文案转换工具（泰语 / 越南语），配合手写机字体 `ARTPHRO-Mix-v3.gfont` 使用。

- 泰语：辅音 + 上下元音 / 声调组合 → 私用区预组合字形（U+E000 起，46 辅音 × 54 组合 = 2484 个）
- 越南语等：统一为 NFC（修正“字母 + 独立声调符号”的分解写法）
- 其他语言原样输出

纯静态单页 `index.html`，无构建步骤，部署在 Vercel。

编码规则：`code = 0xE000 + (辅音码位 - 0x0E01) * 64 + 组合序号`，组合顺序见 `index.html` 中的 `VAR` 定义，必须与字体保持一致。
